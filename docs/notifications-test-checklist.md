# Notification Test Checklist

- First owner session requests notification permission once.
- Allowed notifications appear with sound when device settings permit it.
- Denied permission has a clear settings path.
- Medication and event reminders create both the expected local alert and inbox item.
- Pet-transfer requests appear immediately in the inbox.
- Opening a notification routes to the correct owner screen.
- Mark read and mark all read persist after restart.
- Account A cannot read account B notifications.
- Notification text does not contain sensitive medical details.
