# Lappo Beta Release Notes

This beta focuses on the pet-owner mobile application:

- pet profiles and avatars;
- owner-managed medical visits and private documents;
- medications, feeding, events, and reminders;
- in-app notifications;
- announcements and pet transfers;
- profile editing, data export, and account deletion.

The discontinued clinic administration and online-booking product is not included.

Use only fake data during development and controlled beta testing.
