# Metrics

## Activation

- Owner creates first pet passport.
- Owner fills at least microchip or contact information.
- Owner adds one preventive care event.
- Owner adds one document metadata item.

## Retention

- Owner returns to view reminders.
- Owner marks a reminder completed.
- Owner updates pet health data after a real-world event.

## Trust

- Public QR card is enabled only after owner review.
- Owner understands which fields are public.
- Sensitive medical records stay private by default.

## Pilot Clinic Metrics

- Clinic creates a visit record.
- Clinic attaches a safe owner-visible document.
- Owner sees clinic data inside the pet passport.
