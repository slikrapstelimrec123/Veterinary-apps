# Політика конфіденційності Lappo

Останнє оновлення: 14 липня 2026 року

Ця Політика пояснює, як сервіс Lappo обробляє персональні дані під час використання мобільного застосунку для ведення ветеринарної картки домашніх тварин.

## 1. Які дані ми обробляємо

Ми можемо обробляти:

- дані акаунта: ім’я, адреса електронної пошти, номер телефону та ідентифікатор користувача;
- дані про домашніх тварин: ім’я, вид, порода, стать, дата народження, вага, забарвлення, номер мікрочипа та фотографії;
- ветеринарні дані тварини: записи про прийоми, діагнози, лікування, рекомендації, препарати, годування та завантажені документи;
- технічні дані, необхідні для автентифікації, безпеки та роботи сервісу.

Lappo не призначений для зберігання медичних даних людей.

## 2. Для чого використовуються дані

Дані використовуються для створення акаунта, автентифікації, ведення картки тварини, показу ветеринарних записів і документів, передавання картки іншому власнику, підтримки користувачів, захисту сервісу та виконання обов’язкових юридичних вимог.

Ми не продаємо персональні дані, не використовуємо їх для рекламного відстеження та не створюємо рекламні профілі.

## 3. Хто може отримати доступ

Власник бачить лише пов’язаних із його акаунтом тварин. Клініка та її уповноважені працівники можуть бачити лише дані, пов’язані з їхньою клінікою та відповідним ветеринарним обслуговуванням. Доступ обмежується технічними правилами Row Level Security.

Для хостингу бази даних, файлів та автентифікації використовується Supabase як постачальник інфраструктури. Якщо користувач обирає вхід через Apple або Google, відповідний постачальник обробляє дані автентифікації за власною політикою конфіденційності. Постачальники отримують лише дані, необхідні для надання їхніх послуг.

## 4. Файли та безпека

Фотографії тварин і ветеринарні документи зберігаються у приватному сховищі. Застосунок використовує тимчасові підписані посилання. Ми застосовуємо контроль доступу та інші розумні технічні заходи, однак жоден спосіб зберігання або передавання даних не гарантує абсолютної безпеки.

## 5. Строк зберігання та видалення

Дані зберігаються, доки потрібні для роботи акаунта та надання сервісу. У застосунку можна подати запит на видалення акаунта. Ми прагнемо завершити обробку протягом 30 днів. Дані, які необхідно зберігати для виконання законодавчих обов’язків, вирішення спорів або захисту безпеки, можуть бути знеособлені та збережені лише на необхідний строк.

## 6. Права користувача

Користувач може попросити надати доступ до своїх персональних даних, виправити їх, отримати копію, обмежити обробку або видалити їх у межах застосовного законодавства. Запит можна подати через застосунок або на адресу підтримки.

## 7. Дані дітей

Lappo не призначений для самостійного використання дітьми молодше віку, з якого вони можуть законно погоджуватися на обробку персональних даних у своїй країні. Якщо ми дізнаємося, що такі дані були надані без належної згоди, ми вживемо заходів для їх видалення.

## 8. Зміни політики

Ми можемо оновлювати цю Політику. Дата останнього оновлення вказана на початку документа. Про суттєві зміни буде повідомлено у застосунку або іншим доречним способом.

## 9. Контакти

З питань конфіденційності та реалізації прав: support@lappo.app

Перед публікацією переконайтеся, що ця адреса існує та регулярно перевіряється. Якщо сервіс належить зареєстрованій компанії або ФОП, додайте сюди повне юридичне найменування та поштову адресу контролера даних.
