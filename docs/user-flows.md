# Owner User Flows

## First Use

1. Register or sign in.
2. Allow notifications when prompted.
3. Create a pet profile and optionally add a photo.
4. Open the pet card.

## Medical Journal

1. Open a pet.
2. Open treatment history.
3. Create a visit record.
4. Enter date, optional place or specialist, reason, symptoms, result, treatment, and recommendations.
5. Attach private documents if needed.

## Daily Care

- add or edit medication;
- add feeding information;
- record an important event;
- receive local and in-app reminders.

## Community

- browse or publish an announcement;
- edit contact information and photos;
- transfer a pet to another registered owner;
- accept or decline an incoming transfer.

## Account

- edit profile;
- configure notifications;
- invite friends;
- export account data;
- request account deletion.
