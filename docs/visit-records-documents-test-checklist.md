# Medical Records And Documents Checklist

- Owner can create a visit without clinic, doctor, or appointment identifiers.
- Optional place or specialist is saved as plain `provider_name` text.
- Editing and deleting an owner record persists.
- A record appears immediately in pet history.
- Owner can attach and open a private document.
- Export contains visit metadata and accessible files.
- Another account cannot read the record or download its documents.
