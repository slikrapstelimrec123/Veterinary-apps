# Clinic Pilot

## Role

The clinic module is no longer the primary MVP acquisition path. It remains a pilot layer for selected clinics that can create or verify visit records and documents.

## Pilot Workflows

- Clinic profile and team setup.
- Basic services and doctor schedule.
- Appointments for controlled testing.
- Visit records connected to pets.
- Clinic-uploaded documents visible to owners when marked safe.

## Not Yet

- Open marketplace positioning.
- Paid subscriptions.
- Public ratings as an acquisition channel.
- Broad self-serve clinic onboarding.

## Mobile Placement

The mobile app keeps clinic access behind a "Clinics - pilot mode" card on the home screen instead of a main tab.
