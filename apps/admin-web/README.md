# Lappo Admin

Закрита внутрішня панель Lappo для перегляду агрегованої аналітики клієнтів,
тварин, міст, оголошень, підписок і підтверджених платежів.

## Доступ

Панель має два незалежні рівні захисту:

1. приватний доступ на рівні хостингу;
2. вхід через Supabase та обов'язкова роль `platform_admin`.

Ключ `service_role` не використовується у браузері. Усі дані читаються через
захищені RPC-функції Supabase.

## Змінні середовища

- `SUPABASE_URL`
- `SUPABASE_ANON_KEY`

## Локальний запуск

```text
npm install
npm run dev
```
